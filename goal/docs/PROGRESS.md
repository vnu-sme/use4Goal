# MAGoalTax Plugin — Progress & Developer Guide

## 1. What Is Built

The `goal` plugin implements **MAGoalTax** — a Multi-Agent Goal Decomposition Taxonomy language — as a first-class USE plugin.

Pipeline completed end-to-end:

```
.goal file  →  ANTLR parser  →  AST  →  MM  →  GoalDiagramView (USE ViewFrame)
```

---

## 2. Language Design

### 2.1 Grammar — `GOAL.g4`

Location: `goal/src/main/resources/grammars/GOAL.g4`

The grammar has 4 top-level sections inside `model { }`:

| Section       | Purpose                                  |
|---------------|------------------------------------------|
| `goals { }`   | Declare goals with actors, intent, decomp|
| `tasks { }`   | Declare tasks with pre/post conditions   |
| `resources { }` | Declare physical/virtual resources     |
| `bind { }`    | Assign tasks to goals, resources to tasks|

### 2.2 Decomposition Types

| Keyword | Semantics                              | Syntax |
|---------|----------------------------------------|--------|
| `SEQ`   | Sequential AND — ordered sub-goals     | `SEQ [G1, G2, G3]` |
| `PAR`   | Parallel AND — concurrent sub-goals    | `PAR [G1, G2]` |
| `XOR`   | Exclusive OR — one branch per condition| `XOR [(cond1, G1), (cond2, G2)]` |
| `IOR`   | Inclusive OR — one or more branches    | `IOR [(c1, G1), (c2, G2)]` |
| `ITER`  | Iteration — repeat until condition     | `ITER [G1] until cond` |

Both **goals** and **tasks** support all 5 decomposition types.

### 2.3 Goal Attributes

```
GoalName {
    actor   : AgentName               // single actor
    actor   : [A1, A2]                // multi-actor
    achieve : condition-expression    // achieve intent
    maintain: condition-expression    // maintain intent
    avoid   : condition-expression    // avoid intent
    decomp  : SEQ [Sub1, Sub2]        // decomposition
}
```

### 2.4 Task Attributes

```
TaskName {
    actor : AgentName
    pre   : condition-expression
    post  : condition-expression
    decomp: PAR [Sub1, Sub2]
}
```

### 2.5 Resources

```
resources {
    ledger : physical
    token  : virtual
}
```

### 2.6 Bind

```
bind {
    GoalName -> tasks [T1, T2]   // goal assigned to tasks
    T1       -> uses ledger      // task uses resource
    T2       -> creates token    // task produces resource
    T3       -> consumes token   // task consumes resource
}
```

## 3. Code Structure

### 3.1 Generated by ANTLR (do not edit)

```
target/generated-sources/antlr4/
  GOALLexer.java
  GOALParser.java
  GOALBaseVisitor.java
  GOALVisitor.java
  GOALBaseListener.java
  GOALListener.java
```

Regenerate with: `mvn generate-sources` inside `goal/`

### 3.2 AST layer — `org.vnu.sme.goal.ast`

| Class           | Represents              |
|-----------------|-------------------------|
| `GoalModelCS`   | Root of parsed model    |
| `GoalDefCS`     | One goal declaration    |
| `TaskDefCS`     | One task declaration    |
| `ResourceDefCS` | One resource declaration|
| `GoalBindCS`    | Goal→tasks binding      |
| `ResourceBindCS`| Task→resource binding   |
| `DecompSpecCS`  | Abstract decomp (base)  |
| `SeqDecompCS`   | SEQ decomp              |
| `ParDecompCS`   | PAR decomp              |
| `XorDecompCS`   | XOR decomp with guards  |
| `IorDecompCS`   | IOR decomp with guards  |
| `IterDecompCS`  | ITER decomp with until  |
| `GuardedRefCS`  | (condition, child-id) pair|

### 3.3 MM layer — `org.vnu.sme.goal.mm`

| Class          | Represents              |
|----------------|-------------------------|
| `GoalModel`    | Runtime goal model      |
| `GoalDef`      | Runtime goal object     |
| `TaskDef`      | Runtime task object     |
| `ResourceDef`  | Runtime resource        |
| `GoalBind`     | Goal→task links         |
| `ResourceBind` | Task→resource links     |
| `DecompSpec`   | Abstract decomp (base)  |
| `SeqDecomp`    | SEQ runtime             |
| `ParDecomp`    | PAR runtime             |
| `XorDecomp`    | XOR runtime             |
| `IorDecomp`    | IOR runtime             |
| `IterDecomp`   | ITER runtime            |
| `GuardedRef`   | Branch with condition   |
| `DecompType`   | Enum: SEQ/PAR/XOR/IOR/ITER |
| `ResourceType` | Enum: PHYSICAL/VIRTUAL  |
| `BindRelation` | Enum: CREATES/CONSUMES/USES |

### 3.4 Parser layer

| Class                      | Role                             |
|----------------------------|----------------------------------|
| `GOALCompiler`             | Entry point: file → GoalModel    |
| `GoalModelBuildingVisitor` | ANTLR tree → AST                 |
| `GoalModelFactory`         | AST → MM                         |
| `GoalLoader`               | Orchestrates compile + open view |

### 3.5 View layer

| Class              | Role                                  |
|--------------------|---------------------------------------|
| `GoalDiagramView`  | JPanel + JSplitPane inside ViewFrame  |
| `GoalViewRegistry` | Static registry for current model/view|

### 3.6 Action & Form

| Class            | Role                              |
|------------------|-----------------------------------|
| `ActionOpenGOAL` | USE plugin action (toolbar/menu)  |
| `GoalModelForm`  | Dialog: file picker + log panel   |

## 4. How to Run

### 4.1 Build

```
cd goal
mvn compile          # compile only
mvn package          # build jar
```

### 4.2 Install into USE

Copy the built jar to the USE plugins directory:
```
target/goal-7.1.1.jar  →  <USE_HOME>/lib/plugins/
```

### 4.3 Launch USE

```
cd <USE_HOME>
java -jar use.jar
```

Then from the menu: **GoalModel Plugin → GoalModel Compiler**

### 4.4 Load a .goal file

1. Click **GoalModel Compiler** in the toolbar or menu
2. The "Load MAGoalTax Model" dialog opens
3. Click **Browse** and select a `.goal` file
4. Click **Compile**
5. The goal tree diagram opens as a new view panel

### 4.5 Sample model

```
model EcommerceOrder {
  goals {
    G_PlaceOrder {
      actor : Customer
      achieve : order.confirmed = true
      decomp : SEQ [G_Browse, G_Pay, G_Confirm]
    }
    G_Browse  { actor: Customer  achieve: cart.filled = true }
    G_Pay     { actor: [Customer, PayGateway]  achieve: payment.ok = true
                decomp: XOR [(payment.method = "card", G_CardPay),
                             (payment.method = "cash", G_CashPay)] }
    G_CardPay { actor: PayGateway  achieve: card.charged = true }
    G_CashPay { actor: Customer    achieve: cash.received = true }
    G_Confirm { actor: System      achieve: order.confirmed = true }
  }
  tasks {
    T_AddToCart { actor: Customer
                  pre:  product.available = true
                  post: cart.filled = true }
    T_ChargeCard { actor: PayGateway
                   pre:  card.valid = true
                   post: card.charged = true }
    T_ConfirmOrder { actor: System
                     pre:  payment.ok = true
                     post: order.confirmed = true }
  }
  resources {
    cart     : virtual
    invoice  : physical
  }
  bind {
    G_Browse  -> tasks [T_AddToCart]
    G_CardPay -> tasks [T_ChargeCard]
    G_Confirm -> tasks [T_ConfirmOrder]
    T_AddToCart    -> uses cart
    T_ConfirmOrder -> creates invoice
  }
}
```
