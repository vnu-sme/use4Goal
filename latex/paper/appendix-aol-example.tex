AOL's textual syntax instantiates a named \texttt{.acl} schema with concrete agents, role/entity instances, and attribute values. Listing~\ref{lst:mtg-aol} gives one snapshot: an initiator, an organizer who is also secretary, and three participants, two with a calendar.

\begin{lstlisting}[basicstyle=\ttfamily\scriptsize,frame=single,breaklines=true,caption={Initial object snapshot in \texttt{mtg\_initial.aol}.},label={lst:mtg-aol}]
aol MeetingSchedulerInitial for "mtg.acl" {
  agent a1, a2, a3, a4, a5;

  group MeetingUnit as unit1 {
    play Initiator   as init1 by a1 { }
    play Organizer   as org1  by a2 { }
    play Secretary   as sec1  by a2 { }
    play Participant as p1    by a3 { hasCalendar = true; }
    play Participant as p2    by a4 { hasCalendar = true; }
    play Participant as p3    by a5 { hasCalendar = false; }

    entity Meeting as m1 { detailsDecided = false; timeChosen = false; }
  }
}
\end{lstlisting}

\texttt{org1} and \texttt{sec1} are the same agent \texttt{a2}, exercising the organizer--secretary compatibility of Figure~\ref{fig:acl-mtg}.
